Seal a file in your browser. Share the encrypted package through a channel you choose. The recipient opens it here with the passphrase and checks the exact bytes. Your file and passphrase stay in this browser session.

01 / Create

Seal a package

Choose any file up to 16 MiB. A separate passphrase protects its content and filename.

02 / Receive

Open a package

Verify the encrypted package, then download the original file. A wrong passphrase or altered package fails closed.

How this path works: AES-256-GCM encryption and SHA-256 verification run locally with your browser’s Web Crypto API. The package is a portable buffered artifact. Strata does not upload it, host it, deliver it to another device, or retain your passphrase. Once another person has the package and passphrase, you cannot remotely revoke their copy. This workspace is a usable file handoff, not the full live Strata Data Port Network or a claim of two-machine transport.
