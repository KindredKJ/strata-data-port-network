Session details

Create an invitation on one device or join one from another device.

WebRTC establishes a DTLS-encrypted peer connection and can work across compatible internet connections. This version uses public STUN discovery but no TURN relay, so restrictive NAT or firewalls can prevent pairing. Manual connection codes may contain network address information—share them only with the intended peer. This is direct WebRTC transport, not a claim that native SDPN QUIC or its 40% latency objective has been verified.

Prefer an encrypted package you can send anywhere?

Strata Workspace seals a file into a portable package you can share using your existing messaging or storage service. The recipient verifies and opens it with the passphrase.
