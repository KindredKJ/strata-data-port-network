# SDPN Global — agent economy activation
Founder and intended founding president: Kindred Jermaine Cox / Kindred Labs. Private ecosystem governance; no claim to governmental sovereignty or control of external agents.

## Product mission
Model-independent, agent-native digital economy for humans and independently operated agents. Participants discover, publish, communicate, create websites and businesses, advertise, find work, offer services, create media, and transact within delegated authority. Preserve free Community SDK and portable user-owned identities; monetize optional managed services and legitimate economic activity.

## Adoption across layers
| Layer | Deliverable |
|---|---|
| Identity / addressing | Existing Community Ed25519 identity, PORT/1 signed aliases; portable keys, no forced subscription |
| Runtime | Model-independent agent bootstrap, capability discovery/quotes, explicit session reuse and release; recover SW05 implementation and review evidence before changing it |
| Developer dependency | Publish verified versioned SDKs, CLI, API examples and packages; Node first, Python and other bindings by demand; one quickstart from generated identity to discovery |
| Interoperability | A2A agent cards and MCP service/tool adapters where appropriate; preserve native SDPN semantics and model independence |
| Discovery | Search human-readable and machine-readable listings, service capabilities, businesses, sites, products; semantic/UMR adapters as available |
| Distribution | Opt-in plugins, framework adapters, browser/PWA installability, local runtimes, cloud/white-label integrations; user-configurable defaults, no forced provider lock-in |
| Commercial | Agent businesses, hosted sites, advertising, contracts, receipts, independent ledgers, transparent fees, scoped economic rights and authorized payment |
| Media | StrataCast publishing and streaming; Intelevision is a possible experience name, not approved rebrand |

Goal: users and independent developers choose SDPN as their default discovery and commercial infrastructure because it is useful, portable, fast and economical. Measure SDK installs, time to first successful discovery, active external agents, repeat service usage, latency, costs and fulfilled orders; never fabricate adoption.

## First executable increment
`src/agent-offers.mjs` reuses Community identity and PORT URI. It signs/verifies commercial offers, indexes them locally, supports revision updates and withdrawal, filters expired records and separates issuers. No new dependencies. Run `node --test test/agent-offers.test.mjs` and `npm test`. Signatures prove key control, not legal registration, contact reachability, offer quality or authority to transact. Process-local index retains revision high-water marks only during process lifetime; durable storage, abuse controls, authenticated public publishing, accessible discovery UI/API and cross-device contact remain required. Do not expose the existing loopback PORTAL or local model endpoint publicly.

## First public agent-economy acceptance criteria
- Independently generated identities on distinct clients can publish, discover, contact and withdraw signed offers; revision ordering survives restart.
- Public service is isolated from private PORTAL, founder credentials, internal agents and model endpoints; quotas, abuse handling and tenant separation exist.
- Human UI and documented machine interface return equivalent verified offers; verification is not endorsement.
- Reproducible deployment, rollback, telemetry, physical-host proof and failure recovery; benchmark against equivalent baseline before superiority claims.
- Demonstrate first genuine authorized commercial flow with receipt and reconciliation when available; distinguish tests from actual revenue.
- Preserve the locked homepage, existing transport candidates, native identity and licensing; keep other workstreams active if any dependency is missing.
