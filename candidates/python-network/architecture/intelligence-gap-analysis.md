# Intelligence gap analysis

The current branch implements governed transport, durable evidence, identity and
tenant boundaries, resource/memory/planning interfaces, and benchmark result
validation. It does **not** establish AOI-1 or any WATT intelligence level.

| Gap | Current truth | Required closure |
|---|---|---|
| Architecture | Cognitive interfaces are local control-plane implementations | Integrate authoritative BRAINSTEM packages and versioned contracts |
| Implementation | No objective interpreter, world model, executor, reflection loop, or proposal workflow is connected | Repository implementations plus end-to-end evidence |
| Models | No model/agent provider is connected or benchmarked | Policy-qualified registry records and reproducible provider evaluations |
| Memory/data | No authoritative cognitive corpus or energy telemetry | Provenance, tenant policy, retention, quality, and truth classification |
| Adaptation | Replanning interface exists; no environment-driven adaptive loop | Held-out adaptation benchmarks and reconciled execution outcomes |
| Learning | Memory append/recall exists; no strategy learning is claimed | Evidence-scored strategies and reviewed EvolutionProposals |
| WATT | Repository, telemetry, sites, and hardware inaccessible | Repository access, real non-actuating capability, then telemetry validation |
| Hardware | No actuation identity or safety envelope | Founder authorization, site authority, rollback, independent safety evidence |
| Legal/provider | No production model, energy, market, or grid contracts | Diligence, contracts, credentials, and founder approval |
