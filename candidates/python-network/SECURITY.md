# Security Policy

This is a private founder-controlled repository.

## Reporting

Report suspected security defects privately to the Kindred Labs founder.
Do not publish vulnerabilities, credentials, wallet materials, infrastructure
details, or exploit demonstrations.

## Secret handling

Never commit API keys, passwords, tokens, private keys, mnemonics, production
connection strings, or encrypted wallet files. Use environment variables or an
approved secrets manager.

Previously exposed development wallet credentials must be treated as compromised.
