# Strata Data Port network

Port Zero is the sole protected origin. External communications, economy, and
WATT ports remain vertically outside the trust boundary. The production control
plane provides a durable port directory, authority-gated registration,
capability discovery, compatibility and health-aware route resolution, a strict
versioned envelope, tenant-scoped persistence, and tamper-evident blocked-route
evidence.

No production destination is connected in this checkout. Communications is
blocked on authorized G3T transport-rail access; economy is blocked on its
authoritative repositories and regulated rail; WATT is
`physical_execution_not_connected`. A request to those ports executes the real
fail-closed lifecycle and persists its blocker; it never returns synthetic
success.

## Integration contracts

- BRAINSTEM and Kindred One submit only through Port Zero.
- Kindred Cloud may host adapters but does not own Port Zero.
- Emit Core is the only operational reconciliation authority.
- G3T Connected is communications provider of record.
- RetroBank remains financial authority; the economy port is bounded only.
- WATT-BLOCK remains record-only.

## Execution-engine status

The routing engine is implemented and locally validated for direct, split, and
multicast behavior using isolated test transports that exercise the production
interfaces. Signed receipt binding, selective disclosure, partial multicast,
retry exhaustion, persistent dead letters, restart visibility, and the Emit Core
fail-closed interface are locally validated. No external transport, destination,
or Emit Core authority is connected; therefore the network is not end-to-end
complete, conformance-passed, externally verified, or production-authorized.
